# 数据落点

> 独立技术设计记录。不改写 `../DESIGN.md`，也不把产品规则再扩一版。本文只划分大模块的数据归宿，不定义字段、Record key 或 API。

序章产品规则已经冻结。后续按模块讨论数据结构时，以本文的归宿为准：先确定一份事实住在哪里，再讨论它的形状。

## 三处归宿

| 归宿 | 是什么 | 这一局会不会变 |
| --- | --- | --- |
| Content | 安装包里的只读定义与资源 | 不会。玩家的行动不改写 Content |
| Realm State | 这一局里跨 Subsystem 共享的业务事实 | 会。它是存档要能恢复的那一份真相 |
| 临时内存 | 当前 Frame、当前模拟或当前画面才需要的工作数据 | 会，但结束或读档时按 Content 和 Realm State 重建 |

判定可以收成三句：

- 每个新游戏都一样、并且玩的过程中不改的，放 Content。
- 这一局里 World、Dialogue、Battle、System Menu 必须对同一份答案达成一致，而且存档后还要在的，放 Realm State。
- 只服务当前一次调用、当前一场模拟或当前一帧画面的，留在内存里。

另有两份文档不是新的数据主人：

- **新游戏初始文档**写在 Game Entry 里。它是启动后写入 Realm State 的种子，不是 Content 资源，也不是存档。
- **存档**是 Realm State 里被选中事实的业务快照。读档时由业务解释这份快照，再用普通提交写回 Realm State。

中心管理器不是单独的数据模块。它是地图上的一个地点；修复卡片是在改角色卡的完整度。

## 模块归宿

| 模块 | Content | Realm State | 临时内存 |
| --- | --- | --- | --- |
| 会话 / Frame | — | — | Frame 栈、Activation、InputTarget、正在调用谁 |
| 系统菜单 | 菜单条目可写在子系统里 | 本局不存放。音量、文字速度是本地偏好 | root / 游戏中菜单实例、光标、未确认操作 |
| 消息 | — | — | 当前这一条模态，确认后消失 |
| 地图与玩家 | 地图、碰撞、传送、默认摆放 | 当前地图、玩家格与朝向、剧情改过的持久位置 | 镜头、走步动画、输入缓冲、寻路 |
| 人物本体 | 身份、性格、职业、默认生活点、功能 | 是否已遇见、剧情造成的位置变化 | 当前地图上的表现实例 |
| 契约与角色卡 | 谁能成卡、基础能力来源、显示名 | 契约、持有者、完整度、在中心还是随身 | 中心里尚未提交的编队草稿 |
| 口袋陪伴 | 同行台词、地点评论 | 已经触发过的口袋事件 | 正在说的一句 |
| 关系 | 初始态度 | affinity、hostile、已经提交的变化 | 战斗结束前尚未写回的变化 |
| 剧情 | 序章拍、任务文本、阶段定义 | 当前拍、一次性事件是否已发生 | 正在执行、尚未提交的事件步骤 |
| 遭遇 | 每张地图的遭遇表、出生点、类型 | 本次进图已经生成的可见实例 | 视野、拦路、追逐、这一步的接触 |
| 对话 | 对话图、选项、条件 | 选择结果写入剧情或关系，对话不另存一份真相 | 当前节点、未提交的选择 |
| 战斗 | 规则、技能、教学战、角色战斗简介 | 结束后写回的卡片完整度与已提交后果 | 战场、Decision、模拟、本场本体 HP、动画 |
| 表现 | 图块、角色图、界面皮肤 | — | Renderer 当前副本与动画 |
| 存档 | — | 快照来自 Realm State，不是另一份真相 | 读档过程中的临时缓冲 |

训练、Guidance、多卡编队已经有归宿：定义在 Content，长期结果在角色卡或剧情 State，进行中的操作在对应 Frame 的临时内存。序章不产生这些事实。

## 谁可以提交

```text
Main
  只持有 Frame 栈

System Menu
  触发新游戏、读档、设置、退出
  不改世界事实

Message
  不持有事实

Dialogue / Battle
  Frame 内只有工作集
  结束时把结果交回 World

World
  提交地图进度、角色卡、关系、剧情、遭遇实例
  把 Dialogue / Battle 的结果写回 Realm State
```

## 存档带走什么

存档只带走稳定事实：

- Realm State 中已提交的业务事实；
- 当前地图；
- 玩家位置与朝向；
- 当前地图已经生成的可见遭遇。

存档不带走：

- Frame 栈；
- 打开中的系统菜单和消息；
- 进行中的对话光标；
- 进行中的战斗模拟；
- Renderer 副本。

因此存档点落在 World 的稳定状态上。对话中途、战斗中途不把当前 Frame 工作集写成存档。

## 序章实际会进入 State 的面

序章真正落进 Realm State 的范围很小：

- 当前地图和玩家位置；
- 双向契约的两张卡；
- 宿敌卡的完整度和随身；
- 序章进行到哪一拍；
- 第一道路上已经生成的遭遇；
- 少量关系和剧情标记；
- 已经播过的口袋触发。

这些模块的字段形状留到逐模块讨论时再定。
