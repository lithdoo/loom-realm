## 实施原则

1. 先冻结最小协议，再并行实现通信两端；
2. 先完成测试子系统，再接入复杂地图子系统；
3. 先建立纵向最小闭环，再增加兼容内容；
4. 每个包只能依赖上层允许的方向；
5. 公共类型不能引用具体地图 DTO；
6. 每个设计结论必须有自动测试或公开夹具；
7. 实施中发现架构问题时，先修改上层设计文档；
8. 路线图只追踪工作，不定义正式行为。
